# Matrix Rain (Android)

- Tap the app icon: the rain runs immediately.
- Short tap on the rain or Back: exit.
- Long-press on the rain: open settings (color, size, speed, trail length, reset).
- Settings > Display > Screen saver > "Matrix Rain": runs as a system screensaver using the saved settings.

## Build without Android Studio
1. Create a new GitHub repository and upload the contents of this folder
   (including the hidden .github folder).
2. Open the Actions tab, wait for "Build APK" to finish (about 3-5 minutes).
3. Open the finished run, download the "MatrixRain-apk" artifact, unzip it.
4. Copy app-debug.apk to your phone and install it (allow "install unknown apps").
